# Working in this repo

This repo is a playground: a collection of small, independent projects.

- **One project, one top-level folder.** Start each new project in its own new folder, named in short kebab-case (for example `panel-brick-glass/`).
- **Leave other projects alone.** Never edit, move, rename or delete another project's folder unless the user explicitly asks for that project to change.
- **Keep projects self-contained.** Each folder has its own README and its own files. Don't add shared build tooling, root-level dependencies or cross-project imports unless asked.
- **Update the index.** When adding a project, add one line for it to the list in the root `README.md`.
- **Branches.** `main` holds the finished projects. Do new work on a branch created from `main`, and open a pull request into `main` when the user asks for one.
