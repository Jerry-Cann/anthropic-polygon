# anthropic-polygon

A playground of small, independent projects, each in its own folder.

## Projects

- [`panel-brick-glass/`](panel-brick-glass/): an animated explainer comparing Soviet panel blocks, load-bearing brick and modern glass-and-panel buildings. [Live page](https://claude.ai/artifact/NZ8LeFdiBv5tC6QZsSCMdf) (private link; share it from the page's Share menu)
- [`game-master/`](game-master/): a Claude Code game table for long narrative text games with logged dice, per-game save folders and rulesets for politics, fantasy and life sim. Run `claude` inside the folder and type `/new-game`.
